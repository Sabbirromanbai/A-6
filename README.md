# 🏋️ FitLog — Workout Library

**FitLog** is a modern, dark-themed workout library and workout planning application built with **Next.js**. It allows users to explore workouts, view detailed exercise information, save workouts for later, and create a personal workout plan.

The application is designed with a clean and responsive interface so users can comfortably use it on desktop, tablet, and mobile devices.

---

## 🚀 Features

* 🏋️ **Workout Library** — Browse workouts from the FitLog API.
* 🔎 **Workout Details** — View workout descriptions, equipment, tags, statistics, and step-by-step instructions.
* 📋 **Today's Plan** — Add workouts to your personal plan and track your selected exercises.
* 💾 **Save for Later** — Save favorite workouts for quick access later.
* ✅ **Mark as Done** — Mark completed workouts and receive instant feedback.
* 🗑️ **Remove Workouts** — Easily remove workouts from Today's Plan or Saved workouts.
* 📊 **Live Workout Metrics** — Track total exercises, workout minutes, and estimated calories.
* ↕️ **Workout Sorting** — Sort workouts by duration, calories, or rating.
* 💾 **Local Storage** — Workout plans and saved workouts remain available after refreshing the page.
* 🔔 **Toast Notifications** — Instant feedback for adding, saving, completing, and removing workouts.
* 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop screens.
* ⚠️ **Custom 404 Page** — Friendly error page for invalid routes.

## 🎯 Core Functionality

### Workout Library

Users can browse available workouts in a responsive card-based layout. Each workout displays important information such as:

* Workout name
* Category / muscle group
* Equipment
* Duration
* Calories
* Rating

### Workout Details

Each workout has a dedicated details page containing:

* Workout image
* Description
* Tags
* Equipment
* Duration
* Calories
* Rating
* Step-by-step instructions
* Add to Today's Plan
* Save for Later

### My Plan

The My Plan page provides:

* Today's Plan
* Saved workouts
* Total exercises
* Total duration
* Total calories
* Workout sorting
* Mark as Done
* Remove workout
* View Details
